# Quibdó Sin Residuos (versión sencilla)

Sitio estático (HTML + CSS + JavaScript). Funciona en GitHub Pages o abriendo `index.html` con doble clic.

## Cuentas de administración
Edita `js/admins.js` y agrega los correos y contraseñas de quienes pueden publicar reportes.
Sin sesión iniciada, el formulario de reportes no aparece.

## Límites de esta versión (por ser un trabajo académico)
- Las contraseñas están en el código: cualquiera que abra "Ver código fuente" puede leerlas. Sirve para mostrar el proyecto, no para proteger datos reales.
- Los reportes se guardan en el navegador (localStorage) del computador donde se publican. Quien abra el sitio desde otro equipo verá solo los ejemplos. Para presentar, publica y muestra los reportes desde el mismo computador.
